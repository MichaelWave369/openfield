# Parallax OpenField

> **Public intelligence with receipts.**  
> See the world. See the sources. See the uncertainty.

Parallax OpenField is an evidence-governed, map-first workspace for collecting public observations, preserving provenance, separating fact from inference, and reconstructing what was known at any point in time.

This foundation build is deliberately honest: the interface uses **clearly labeled synthetic demo events** while the receipt model, claim boundaries, confidence math, APIs, governance, and tests are established. Live connectors arrive only after source licensing, health, and provenance requirements are enforceable.

## Included in v0.1 foundation

- Interactive global operations console
- Observation, claim, inference, forecast, contradiction, and unknown boundaries
- Evidence receipt inspection
- Transparent confidence decomposition
- Synthetic Data Center Watch mission
- Typed event API
- Architecture, governance, security, and roadmap documents
- Unit tests and GitHub Actions CI

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Run the full validation suite with `npm run check`.

## API

- `GET /api/health`
- `GET /api/v1/events`

## Truth boundary

OpenField never silently turns generated prose into evidence. Every record remains explicitly classified, every inference names its dependencies, and every unknown stays visible.

## Principles

1. Evidence before narrative.
2. Provenance survives transformation.
3. Freshness and source health remain visible.
4. Contradiction and dissent are retained.
5. Human operators retain final authority.
6. Privacy and civil liberties are architectural constraints.
7. Synthetic data never masquerades as live intelligence.
