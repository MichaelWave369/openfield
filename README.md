# Parallax OpenField

**Public intelligence with receipts.**

Parallax OpenField is an evidence-governed, map-first intelligence workspace for collecting public observations, preserving provenance, separating fact from inference, and reconstructing what was known at any point in time.

This repository is being initialized from the Parallax OpenField Research Constitution, Master Architecture & Formula Specification v0.1.

> See the world. See the sources. See the uncertainty.

## Status

Early foundation build. The application scaffold and first reference mission will arrive through reviewable pull requests.

## Core commitments

- Evidence before narrative
- Observation, claim, inference, and forecast remain distinct
- Every generated conclusion points back to inspectable receipts
- Freshness, uncertainty, contradiction, and dissent stay visible
- Human operators retain authority
- Privacy and civil liberties are architectural requirements
