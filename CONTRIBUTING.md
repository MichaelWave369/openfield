# Contributing

OpenField is built around evidence custody, visible uncertainty, and human authority.

Before contributing:

- Keep observations, claims, inferences, forecasts, contradictions, and unknowns distinct.
- Do not add live sources until licensing, attribution, refresh behavior, and failure states are documented.
- Never commit credentials, private surveillance material, or personal data.
- Mark every fixture and screenshot as synthetic when it is not live.

Run `npm run check` before opening a pull request. Architectural decisions belong in `docs/adr/`.
